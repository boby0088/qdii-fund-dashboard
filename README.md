# QDII 定投雷达

每天定投纳斯达克100 / 标普500 指数基金（含主动型全球美股基金）的辅助工具。**场外基金盯「单日申购限额」，场内 ETF 盯「溢价率」**，跟踪全部人民币份额（A/C/D/E/I/F 类及主动型，美元份额除外），并按「溢价率低 → 持有费率低 → 跟踪偏离低」综合排序展示。

**在线访问**：[https://boby0088.github.io/qdii-fund-dashboard/](https://boby0088.github.io/qdii-fund-dashboard/)

> 在线版为静态快照，由 GitHub Actions 在每天（北京时间 06:30 / 12:30）自动刷新并发布；本地运行 `python run.py serve` 可获得实时数据与手动刷新。

## 快速开始

```bash
# 1. 拉取最新数据并打印简报（命令行）
python run.py refresh

# 2. 启动本地 Web 仪表盘（默认 http://127.0.0.1:8765 ）
python run.py serve
# 或指定端口
python run.py serve 9000
```

Windows 也可以直接双击 `启动仪表盘.bat`（会自动找 python 并打开浏览器）。

> 纯 Python 标准库实现，**无需安装任何第三方包**。仅在本机运行，不上传任何数据。

## 功能

- **场内 ETF（16 只）**：最新价、最新净值、溢价率（= 现价 ÷ 最新净值 − 1，QDII 净值 T-1 披露）、涨跌幅、成交额、管理费率、跟踪偏离估算，按综合分排序。
- **场外人民币份额（53 只）**：申购状态、单日累计申购限额（实时解析）、标准申购费率、管理费/托管费/销售服务费、跟踪偏离估算。**自动过滤「单日限额 ≤ 1元」「暂停申购」「暂不开放购买」** 的品种，被过滤名单在页面折叠区展示（区分「买不了」与「没统计」）。
- **指数筛选**：全部 / 纳斯达克100 / 标普500 / 全球美股。
- **数据时间戳 + 一键刷新**：页面每 5 分钟自动更新，也可手动「立即刷新」。

## 排序口径（综合分 = 加权排名之和，越低越优先）

| 通道 | 权重 |
| --- | --- |
| 场内 ETF | 溢价率 50% + 管理费率 30% + 跟踪偏离 20% |
| 场外 A/C/D/E | 持有费率(10年口径) 60% + 跟踪偏离 40%（先过滤 限额≤1元/暂停申购） |

- **溢价率**：场内的核心成本，偏高（>2%）时当日不宜场内买入。
- **跟踪偏离（估算）**：近约120个交易日日收益率与同指数基金中位数的年化标准差，用于品种间相对比较。
- **持有费率（10年口径）= (管理费+托管费+销售服务费)/年 + 标准申购费率/10**：以持有10年为前提，把一次性申购费摊到10年（÷10），使 A 类（有申购费、无销售服务费）与 C/D/E/F/I 类（申购费为0、按年收销售服务费）在「长期持有成本」同一口径下公平比较。表格列「管+托+销%」展示的是不含申购费的每年费率之和。美元现汇/现钞份额不纳入（无法用人民币定投）。

## 数据来源与免责声明

数据来自东方财富 / 天天基金公开接口，仅供个人投资研究参考，不构成投资建议。
接口字段可能随网站改版而变化；费率等静态数据已核验于 `fees_updated` 日期，之后如有变动请以基金公告为准。

## 常见问题

- **提示「场内行情抓取失败」**：东方财富 push2 接口偶发限流，稍等后点「立即刷新」即可（代码内置了备用域名与重试）。
- **某只基金未出现在场外列表**：说明其当前「暂停申购」或「单日限额 ≤ 1元」，属于有意过滤。
- **想加/减基金**：编辑 `watchlist.json` 的 `funds` 数组（`channel` 为 `etf` 或 `otc`），费率字段按相同格式填写。**只加人民币份额（A/C/D/E/F/I 均可）**，美元现汇/现钞份额不纳入。指数字段 `index` 支持 `nasdaq100` / `sp500` / `globalus`（主动型全球美股，如浦银全球智能科技、嘉实美国成长）。
