数据口径：溢价率 = (最新价 − 最新单位净值) ÷ 最新单位净值 × 100%（QDII 净值按 T-1 披露，溢价率为估算值）；跟踪偏离 = 近约120个交易日的日收益率与同类中位数的年化标准差（相对估算，用于排序）；综合分 = 加权排名之和（场内 溢价率50%+管理费30%+偏离20%；场外 持有费率60%+偏离40%）。场外持有费率按10年持有假设：持有费率 = (管+托+销)/年 + 标准申购费率/10，把一次性申购费摊到10年，使 A/C 在长期持有成本上口径一致。越低越优先。表格费率列口径：场内「管理+托管费%」= 每年管理费率+托管费率；场外「管+托+销%」= 每年管理费率+托管费率+销售服务费率。数据来源：东方财富 / 天天基金公开接口，仅在本机运行。
